# EW Clock Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, verify, sign, and upload EW Clock for iPhone, iPad, and Mac, then distribute both builds to the intended internal TestFlight group.

**Architecture:** Two native SwiftUI app targets share formatting, typography, resources, and the clock view. Platform-specific entry points manage scene presentation and display-sleep prevention. XcodeGen owns the generated project, shell scripts own repeatable local builds and archives, and App Store Connect owns beta distribution.

**Tech Stack:** Swift 6, SwiftUI, Foundation, CoreText, UIKit, AppKit, XCTest, XcodeGen, Xcode 26.6, App Store Connect, and TestFlight.

## Global Constraints

- Product name is `EW Clock`; write `EVERYWOW` everywhere else.
- Bundle identifier is `ch.everywow.clock`; SKU is `everywow-clock`.
- Version is `1.0`; initial build number is `1`.
- Minimum systems are iOS 26.0, iPadOS 26.0, and macOS 26.0.
- The time is `hh:mm:ss`, white on black, centered, horizontal, and exactly 90% of available width.
- Use EVERYWOW Display weight 900 through PostScript name `EVERYWOWDisplay-Black`.
- Add no controls, settings, gestures, networking, analytics, or persistence.
- Work directly on `main`, commit focused working changes, and push completed work.

## File Structure

- `project.yml`: XcodeGen source for iOS, macOS, and unit-test targets.
- `EWClock/Shared/ClockTime.swift`: current-time decomposition and 24-hour formatting.
- `EWClock/Shared/ClockTypography.swift`: CoreText advance measurement and 90% scaling.
- `EWClock/Shared/BrandFont.swift`: bundled font registration.
- `EWClock/Shared/ClockView.swift`: shared SwiftUI clock presentation.
- `EWClock/iOS/EWClockIOSApp.swift`: iOS scene and overlay behavior.
- `EWClock/iOS/IOSDisplaySleepController.swift`: UIKit idle-timer lifecycle.
- `EWClock/macOS/EWClockMacApp.swift`: resizable Mac window.
- `EWClock/macOS/MacDisplaySleepController.swift`: macOS display-sleep assertion.
- `EWClock/macOS/EWClockMac.entitlements`: App Sandbox entitlement for Mac App Store distribution.
- `EWClock/Resources/`: font, launch color, and universal app-icon assets.
- `EWClockTests/`: formatter and typography unit tests.
- `script/`: repeatable generation, build, test, archive, and upload commands.
- `.codex/environments/environment.toml`: Codex Run action.
